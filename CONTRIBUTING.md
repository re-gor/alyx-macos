# Contributing

Unsupported vibe-coded hobby project; original additions are MIT. See [development](docs/en/development.md) / [разработка](docs/ru/development.md).

Retain upstream notices, exact binary/ABI guards, scoped ownership and GPU-completion synchronization. Do not replace managed-prefix stops with global kills. Do not add credentials, account folders, SDK/framework/game binaries, raw captures or device IDs.

A passing build/unit test is not proof of VR playback. Separate offline, native synthetic and actual headset acceptance. Describe versions and limitations in both languages. Compare the same scene and distinguish encoded attempts, fresh decoder cadence and game GPU time.
