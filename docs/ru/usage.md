# Запуск, ALVR Settings и остановка

[English](../en/usage.md) · [Установка](install.md)

Вызывайте скрипты из проекта или по абсолютному пути. Добавляйте тот же `--root PATH`, что при установке.

| Задача | Команда |
|---|---|
| Windows Steam | `./scripts/start_steam.sh` |
| ALVR Dashboard напрямую | `./scripts/start_alvr.sh` |
| Настройки ALVR | `./scripts/alvr_settings.sh` |
| Alyx вместе с VR, USB и звуком | `./scripts/launch_alyx.sh` |
| Запросить загрузку save | `./scripts/launch_alyx.sh --save s0/quick` |
| Проверка только картинки | `./scripts/launch_alyx.sh --no-audio` |
| Переподключить выбранный шлем | `./scripts/connect_headset.sh` |
| Остановить эту бутылку | `./scripts/stop.sh` |
| Состояние наблюдателя игры | `./scripts/audio_status.sh` |
| 30с метрик видеопотока | `./scripts/measure.sh --seconds 30` |

Для настроек откройте Dashboard и выберите **Settings**. Установщик повторно запускать не нужно. Работающий собственный сервер доступен также на `http://127.0.0.1:8083/`. Исходная отладочная оболочка использовала 8082.

## ALVR как сторонняя игра Steam

Один раз войдите в этот Windows Steam, выйдите из него, затем:

```sh
./scripts/stop.sh
./scripts/add_alvr_to_steam.sh
```

Скрипт делает бэкап binary `shortcuts.vdf`, сохраняет существующие записи и добавляет **ALVR Dashboard (alyx-macos)**. Если аккаунтов несколько, выберите числовой userdata-каталог через `--steam-userid`. Потом откройте `SteamVR.app` в Finder, найдите ALVR в библиотеке Steam и нажмите **Играть** — для последующего открытия Settings терминал не нужен.

Вручную: Steam → Игры → Добавить стороннюю игру → Обзор → `C:\ALVR\ALVR Dashboard.exe` → Добавить выбранные.

## Обычный запуск через Steam

1. Подключите Quest по USB, наденьте его и откройте ALVR в шлеме. После подключения кабеля создайте туннель нативным Mac adb: `./scripts/connect_headset.sh`. Если туннель пропал, повторите команду. Скрипт использует выбранное авторизованное устройство и не останавливает чужие adb-серверы.
2. Откройте `SteamVR.app` в Finder. Несмотря на имя, оболочка открывает **Windows Steam**. Дождитесь библиотеки и окончания входа в аккаунт.
3. В этой библиотеке запустите **ALVR Dashboard (alyx-macos)**, затем SteamVR через ALVR или Steam.
4. Оставьте **Settings → Audio → Game audio** включённым. Адаптер выбирает активную игру SteamVR автоматически. Создавать `audio-source.pid` и выбирать PID вручную больше не нужно.
5. Один раз задайте в Steam **Свойства Alyx → Общие → Параметры запуска**:

```text
-dx11 -nomultiview -novid +vr_fidelity_level_auto 0 +vr_fidelity_level 3 +vr_msaa 2
```

6. Запустите Alyx из Steam. Наденьте Quest, возьмите оба контроллера и проверьте картинку, управление и слышимый звук игры.

Фоновый наблюдатель выбирает только процесс активной игровой сцены. Пока подходящая игра не запущена, источник пустой. Код умеет менять источник без перезапуска vrserver; переключение между произвольными VR-играми в шлеме пока не проверено. Подробности и обновление: [звук](audio.md).

## Обновление запуска Steam

Новые оболочки и `configure.sh` сохраняют `-vrdisable` в **Info.plist → Program Flags** для **Steam.exe**. Finder и `start_steam.sh` используют сохранённое значение. Флаг отключает собственную OpenVR-интеграцию обычного клиента Steam; Alyx продолжает работать через OpenVR → SteamVR → ALVR → Quest. Не добавляйте этот флаг в параметры Alyx, SteamVR или ALVR.

Для существующей установки получите обновление, закончите текущую игровую сессию и выполните:

```sh
git pull --ff-only
./scripts/stop.sh
./scripts/fix_steam_startup.sh
./scripts/start_steam.sh
```

Если установка находится в другом каталоге, добавьте одинаковый `--root PATH` ко всем трём скриптам. `stop.sh` закрывает эту управляемую бутылку вместе с запущенной игрой. Само исправление ничего не запускает и не завершает, отказывается менять работающую бутылку или оболочку с другой программой, сохраняет Info.plist в `backups/steam-startup-*` и однократно добавляет флаг. Существующие аргументы Steam и остальные настройки сохраняются. Пересборка адаптеров, сброс профиля и отдельный launcher для каждой игры не нужны. Затем используйте обычный порядок запуска выше.

На исходной установке со Steam **1791918634** и SteamVR **2.17.10** это вернуло работу обычной кнопки «Играть». SteamVR подключился к Steam за 0,14 с вместо повторяющихся тайм-аутов примерно по 5 с. Точный заблокированный вызов и роль обновления Steam не установлены; флаг не исправляет все последующие сбои SteamVR.

## Запуск скриптом

`launch_alyx.sh` остаётся необязательным способом полного холодного запуска: отклоняет другой работающий VR-prefix, останавливает только свою бутылку, запускает Steam/ALVR/vrserver/compositor, проверяет стабильность Steam, запускает Alyx с сохранёнными fidelity/MSAA и переподключает USB. Звук включается до игры и выбирается автоматически. `--no-audio` оставляет Game audio выключенным для диагностики.

Холодный перезапуск — выбор launcher, **а не необходимость выбирать новый PID звука**. `--save` запрашивает существующее сохранение; меню может потребовать действия. Если macOS запросит согласие на захват, разрешите его для указанной оболочки/терминала. Отсутствие запроса само по себе не доказывает сбой.

`make_gui_launcher.sh` может создать необязательный `Alyx VR.app` для полного запуска скриптом. Для обычного Steam он не нужен; отдельная проверка этого ярлыка после установки с нуля не выполнялась. Не перемещайте repo/Python; лог находится в `logs/gui-launch.log`. Старые отдельно созданные ярлыки могут загружать прежний адаптер — не используйте их вместо обновления.

## Приватное состояние и бэкапы

В каталоге установки: `settings.json`, `downloads/`, `backups/`, `logs/`. `index.json` бэкапа показывает исходные относительные пути. Перед восстановлением настроек/библиотек остановите эту бутылку; разные версии sharing-протокола на ходу не смешивайте. Логи перед публикацией просматривайте и редактируйте: там могут быть имя пользователя, device ID и сетевые сведения. Не выкладывайте весь prefix, аккаунт Steam, save или сырые записи.
