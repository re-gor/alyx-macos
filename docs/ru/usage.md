# Запуск, ALVR Settings и остановка

[English](../en/usage.md) · [Установка](install.md)

Вызывайте скрипты из проекта или по абсолютному пути. Добавляйте тот же `--root PATH`, что при установке.

| Задача | Команда |
|---|---|
| Windows Steam | `./scripts/start_steam.sh` |
| ALVR Dashboard напрямую | `./scripts/start_alvr.sh` |
| Настройки ALVR | `./scripts/alvr_settings.sh` |
| Alyx вместе с VR, USB и звуком | `./scripts/launch_alyx.sh` |
| Запросить загрузку save | `./scripts/launch_alyx.sh --save s0/quick` |
| Проверка только картинки | `./scripts/launch_alyx.sh --no-audio` |
| Переподключить выбранный шлем | `./scripts/connect_headset.sh` |
| Остановить эту бутылку | `./scripts/stop.sh` |
| Готовность звукового источника | `./scripts/audio_status.sh` |
| 30с метрик видеопотока | `./scripts/measure.sh --seconds 30` |

Для настроек откройте Dashboard и выберите **Settings**. Установщик повторно запускать не нужно. Работающий собственный сервер доступен также на `http://127.0.0.1:8083/`. Исходная отладочная оболочка использовала 8082.

## ALVR как сторонняя игра Steam

Один раз войдите в этот Windows Steam, выйдите из него, затем:

```sh
./scripts/stop.sh
./scripts/add_alvr_to_steam.sh
```

Скрипт делает бэкап binary `shortcuts.vdf`, сохраняет существующие записи и добавляет **ALVR Dashboard (alyx-macos)**. Если аккаунтов несколько, выберите числовой userdata-каталог через `--steam-userid`. Потом откройте `SteamVR.app` в Finder, найдите ALVR в библиотеке Steam и нажмите **Играть** — для последующего открытия Settings терминал не нужен.

Вручную: Steam → Игры → Добавить стороннюю игру → Обзор → `C:\ALVR\ALVR Dashboard.exe` → Добавить выбранные.

Этот ярлык открывает Dashboard, но не выполняет весь упорядоченный запуск игры/звука. Для Finder-ярлыка полного bootstrap:

```sh
./scripts/make_gui_launcher.sh
```

Создаётся `Alyx VR.app` в приватном каталоге, лог — `logs/gui-launch.log`. GUI/game/audio acceptance не проверен; не перемещайте repo/Python без пересоздания ярлыка.

## Известная проблема старта звука

При ручном GUI-старте наблюдались тишина в шлеме/E_NOTIMPL; исправление ещё исследуется в исходном эксперименте. Отдельно Steam иногда завершался, и Alyx падала на SteamAPI ещё до создания audio. В пакете добавлена проверка стабильности собственного Steam перед игрой, но это **не доказанное полное исправление** GUI/audio. Постоянный кэш неудачи при отсутствии source не доказан. Исторический работающий звук и offline tests не подтверждают каждый новый запуск.

## Порядок полного запуска

1. Не использовать шлем, пока работает другой VR Wine-prefix.
2. Остановить только эту бутылку и убрать старый PID аудиоисточника.
3. Открыть Steam, подождать 30с инициализации; запустить ALVR, vrserver и vrcompositor без невидимого Dashboard/Home/monitor.
4. Запустить Alyx с DX11, фиксированным fidelity и выбранным MSAA.
5. Дождаться вывода звука новой игры, выбрать её PID, включить GameAudio и переподключить USB-клиент.

Холодный перезапуск нужен: tap хранит один источник до выхода vrserver. Перезапуск одного `hlvr.exe` может оставить звук на старом процессе. Чужой prefix и все Wine-процессы глобально не завершаются.

Steam может показать вход/установку/подтверждение после сбоя. macOS — согласие на захват. Quest — USB debugging. Наденьте шлем, оставьте ALVR открытым, возьмите оба контроллера, закройте предупреждение и загрузите save, если осталось меню.

Launcher передаёт `+vr_fidelity_level_auto 0 +vr_fidelity_level 3 +vr_msaa 2` с сохранённым MSAA. Обычная кнопка **Играть** в Steam сама эти флаги не наследует. `--save` просит загрузить существующий файл, но стартовое меню может всё равно потребовать действия.

## Приватное состояние и бэкапы

В каталоге установки: `settings.json`, `downloads/`, `backups/`, `logs/`. `index.json` бэкапа показывает исходные относительные пути. Перед восстановлением настроек/библиотек остановите эту бутылку; разные версии sharing-протокола на ходу не смешивайте. Логи перед публикацией просматривайте и редактируйте: там могут быть имя пользователя, device ID и сетевые сведения. Не выкладывайте весь prefix, аккаунт Steam, save или сырые записи.
