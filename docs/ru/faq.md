# FAQ и решение проблем

[English](../en/faq.md) · [Настройки](settings.md)

Проект навайбкоженный. Помогший на одной машине обход не гарантирует результат. Сохраняйте бэкапы и меняйте одну ручку за раз.

## Камера в меню кривая, смещена или странно следует за головой

Закончите настройку трекинга/границ Quest. ALVR должен быть открыт, оба контроллера — в руках. В исходном сеансе иногда помогало снять/надеть шлем, перевести в сон и разбудить, при необходимости открыть ALVR заново. Factory reset не требовался и не проверялся. Переподключение может поставить Alyx на паузу: продолжите/загрузите save до оценки FPS.

## Connected есть, картинка чёрная/бирюзовая

Connected — управляющее соединение, не доказательство пикселей. Проверьте версии, загрузку адаптера и `allowDisplayLockedMode=true`. Запустите `doctor.sh`, затем холодный `launch_alyx.sh`. Исходная бирюза была связана с shared resources и ложным статусом заблокированного сеанса Wine. Не отключайте GPU completion ради случайного обхода.

## SteamVR 461 / critical failure

Проверьте Wine 10.0_6/template 1.0.11 и SHA ALVR DLL. Смотрите свои `logs/vrserver.log`/`vrcompositor.log` на отсутствие адаптера/неподдержанные версии. Собирайте/настраивайте при остановленной бутылке, затем стартуйте холодно. Новые SteamVR/Wine могут потребовать ABI-работы; guards не отключайте.

## Mongoose timeout / WebHelper

Используйте скрипты с `CX_FWD_COMPAT_GL_CTX=1`. Отдельные текстуры WebUI в исходной связке имели ограничения. Dashboard отключён намеренно: его включение может снова невидимо перехватить ввод.

## Нет рук или кнопки не работают

Возьмите оба контроллера. Нужен официальный x64 MSVC runtime/native override только для `vrserver.exe`; Dashboard/autolaunch выключены. Используйте полный launcher. Thumb-touch пока недоведён — это отдельное ограничение, а не полный отказ трекинга.

## Правый глаз дрожит/отстаёт

Нужен текущий keyed mutex с проверкой владельца. После библиотечных обновлений холодно перезапускайте всех участников. Разные протоколы не смешивайте. Ошибочный foreign release нарушал владение; после исправления были GPU visibility tests и проверка в шлеме. Completion synchronization ради FPS не убирайте.

## Нет звука в шлеме / E_NOTIMPL

Обновите и настройте [автоматический аудиоадаптер](audio.md), затем один раз холодно перезапустите бутылку, чтобы загрузить новую библиотеку. Game audio должен быть включён, ALVR в Quest — открыт на переднем плане. Новый адаптер следует за активной сценой SteamVR; сохранять PID Alyx вручную больше не нужно. `audio_status.sh` читает состояние наблюдателя, не PCM; `ready` подтверждает сопоставление процессов, а не слышимый звук. Без игры источник пустой.

Проверьте согласие на захват для указанной macOS оболочки/терминала. Отсутствие нового запроса не доказывает сбой. Неизвестные Wine/watcher намеренно отклоняются — guards сохраняйте. Повторный `0x80004001` сам по себе не устанавливает причину. Если адаптер перешёл в небезопасное состояние, остановите свою бутылку и запустите заново; tap, которым ещё владеет Wine, не уничтожайте. Играм со звуком в отдельном процессе нужна дополнительная поддержка.

## Голоса роботные/звук прерывается

Референс: host capacity 100мс, client average 50мс/batch 10мс. Ёмкость не равна фиксированной задержке. Сравните один звук на Mac/Quest. Не меняйте 44100→48000 наугад: аппаратный resampling может быть нормальным. Видеобитрейт не восстановит потерянное upstream-аудио.

## Меню/эмбиент есть, разговоры/взаимодействия пропали

Сначала сравните с Mac. Если и там звуков нет, они отсутствуют ещё в игре. В исходном сеансе сохранение/загрузка вернули звук; причина не доказана, патч аудиодвижка не писали.

## Не удалось запустить Vulkan

Используйте DX11:

```sh
./scripts/stop.sh
./scripts/fix_vulkan.sh
./scripts/launch_alyx.sh
```

Скрипт делает бэкап и возвращает наблюдавшийся выбор `boot.vcfg`. Поддержку Vulkan VR не реализует.

## Мыло при высоком разрешении

Проверьте auto-fidelity off/level 3 и размеры render/encode. Окно на Mac имеет отдельный размер. Битрейт улучшал детали; all-I software требует большого потока. FFR намеренно снижает детализацию краёв — оцените и центр. См. [настройки](settings.md).

## Видео отстаёт на секунды, звук реагирует

Возможна очередь видео; это не доказывает слабый GPU игры. FIFO 2 ограничивает одну очередь. С мелкими блоками/pacing off были Full drops и задержка; последующий 16КиБ/90Гц/off доставлял больше без наблюдавшегося queue-full. Kernel/adb/client buffers отдельные. Попробуйте холодное переподключение и замер стабильной сцены.

## Подгонять герцовку под средний FPS?

Автоматически — нет. 90Гц позволяют показывать/reproject старую картинку между новыми кадрами. 72Гц меняют и framerate/VBV SW-кодека; в тесте вырос размер кадра и упала доставка. Pacing влияет на ожидание/backpressure. Оценивайте ощущения, задержку и корректную FPS-метрику вместе.

## UDP/Wi-Fi?

Упакован USB/TCP. adb TCP не туннелирует UDP; ALVR на loopback/wired принудительно выбирает TCP. 16КиБ не годятся как общий UDP datagram size. Wi-Fi припаркован, end-to-end не проверен. Перед отдельным беспроводным тестом верните 1400.

## adb: нет устройства / unauthorized / несколько устройств

Нужны data-кабель, Developer Mode, USB debugging и подтверждение компьютера внутри Quest. Используйте `--serial`. Не убивайте весь adb во время чужого сеанса. Снятие шлема/фон ALVR может штатно отключать поток.

## Это готовый поддерживаемый продукт?

Нет. Исходная интерактивная установка игралась; сборка/офлайн-проверки пакета — отдельные результаты, fresh install ещё не подтверждён. Guards намеренно отклоняют неизвестные binaries/layouts. Для отчёта используйте короткие отредактированные версии/симптомы, а не аккаунт или сырые записи.
